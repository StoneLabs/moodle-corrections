How it works

  1. Paste the student's text on the left. Bold, italic and underline are kept. It is copied to the right automatically until you start editing there.
  2. Correct the right side. Removed words light up red, added words green. Changing a word's formatting also counts as a correction.
  3. Type [[your note]] anywhere — or press Ctrl M — for a gray comment. A note on a line of its own stays on its own line.
  4. Can't tell what a sentence means? Put the cursor in it and click ? Unclear (Ctrl ?), or type [? … ?] around it. It turns yellow with ? … ? around it. Click again inside it to remove the mark.
  5. Not wrong, but better without? Put the cursor on the word (or select the words) and click Without, or type [~ … ~] around it. It gets a red underline. Click again inside it to remove the mark.
  6. Format with the toolbars or Ctrl B / I / U.
  7. Press Ctrl Enter (or Copy for Moodle) and paste into Moodle's feedback editor with Ctrl V.

What gets copied is assembled by the Output template (see the tab above). Everything stays in this browser: your draft, signature, template and settings are saved locally, and nothing is uploaded.

Variables

The corrected text with removals, additions and notes.
{{ original }}
The student's text, unmarked.

Your correction without markings or notes.
{{ feedback }}
Your feedback.

Your signature.

Number of corrections, notes, unclear and better-without passages.

Helpers

| collapsible("Title")
A section the student opens with a click. Add , true after the title to start it open. Empty values produce nothing.
{{ legend() }}
A colour key. Own labels: legend("removed", "added", "note", "unclear", "better without")

Jinja

Full Jinja syntax (Nunjucks), for example {% if feedback %}…{% endif %}, {% if changes == 0 %} or {# comment #}. Empty fields count as false. Values are already HTML.
